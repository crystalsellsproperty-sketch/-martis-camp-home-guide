# Martis Camp Home Guide

Independent luxury real estate website starter for Crystal Bauer | eXp Realty.

## Run

`npm install`

`npm run dev`

## Deploy

Import this repository in Vercel as a Next.js project. Verify its temporary `.vercel.app` URL before connecting Namecheap DNS.

## Important before public launch

- Add approved brokerage and agent license disclosures.
- Obtain approval for community naming and any third-party photography.
- Connect authorized property feeds; sample pages intentionally contain no invented listings.
- Implement and test a privacy-compliant lead form and Lofty CRM integration.
- Change `app/robots.ts` to permit indexing only after launch clearance.
- Set up Search Console, analytics, and appropriate privacy policy.

No environment secrets or contact credentials belong in this repository.
